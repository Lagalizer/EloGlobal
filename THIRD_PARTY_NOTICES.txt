EloGlobal - third-party software, models, voices and fonts
=========================================================

EloGlobal itself is MIT-licensed (see LICENSE). It is built on the components below. The complete licence text
of every component is in the licenses\ folder of the installed app (collected by tools\build_store.py from each
package), together with the source code of eSpeak NG.

"Shipped" = included in the app package. "Downloaded" = fetched once from its publisher when the feature is first
used (the user's PC downloads it directly; the app sends nothing else). Nothing in this list forbids commercial use.

---------------------------------------------------------------------------------------------------------------
eSpeak NG 1.52.0                GPL-3.0-or-later            (c) Reece H. Dunn, Jonathan Duddington and contributors
  engines\espeak-ng\espeak-ng.exe, libespeak-ng.dll and espeak-ng-data, unmodified, from the official release

5. Fonts, icons and artwork
---------------------------------------------------------------------------------------------------------------
EloGlobal logo, app icon and store graphics - original artwork made for EloGlobal (MIT, see LICENSE).
  The letters of the wordmark are outlines of Poppins SemiBold, (c) 2020 The Poppins Project Authors,
  SIL Open Font License 1.1 (the font file is not shipped).
The app uses the fonts installed in Windows (Segoe UI); no font is shipped.
Emoji shown in the interface are drawn by Windows' own emoji font.

---------------------------------------------------------------------------------------------------------------
6. Left out on purpose
---------------------------------------------------------------------------------------------------------------
PyAV / FFmpeg     its Windows wheels contain GPL encoders (x264, x265); faster-whisper only needs it to decode
                  audio files, which EloGlobal never does - a stand-in module answers the import.
piper-tts 1.3+, phonemizer, espeakng-loader   GPL-3 code that would run inside the app process; replaced by our
                  own MIT runners and the separate eSpeak NG program (section 2).
NLLB-200          CC-BY-NC-4.0 (non-commercial).
VB-Audio Virtual Cable   not included - the app only links to https://vb-audio.com/Cable/ ; users install it
                  themselves under VB-Audio's own licence.
Online services (Google, Microsoft Edge voices, OpenAI, DeepL...)   not used - everything runs on the PC.

Qt / LGPL
---------------------------------------------------------------------------------------------------------------
EloGlobal uses the Qt 6.11 libraries through PySide6 under the GNU Lesser General Public License v3
(licenses\PySide6). The Qt and PySide6 DLLs in runtime\Lib\site-packages\PySide6 and shiboken6 are unmodified and
dynamically loaded - you may replace them with your own builds of the same version. Source code: Qt
https://download.qt.io/official_releases/qt/6.11/ and PySide6 https://code.qt.io/cgit/pyside/pyside-setup.git
(tag v6.11.2). On request (see the store page for the contact) we will send you a copy of that source code.
The same applies to pynput (LGPL-3.0) and libsndfile (LGPL-2.1).
